# Logotipos de proveedores

Los archivos SVG se sirven localmente para que la interfaz no dependa de una URL externa en tiempo de ejecución.

- OpenAI/ChatGPT y Claude: recursos publicados en el directorio de logos de SVGL, que enlaza cada marca con su web oficial.
- Microsoft Copilot: recurso SVG de SVGL para Microsoft Copilot.
- Google Gemini y Perplexity: iconos SVG del proyecto Simple Icons.

Las marcas y logotipos pertenecen a sus respectivos propietarios. Se usan aquí únicamente para identificar el proveedor enlazado.
